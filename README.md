# Лабораторна робота №6. Відображення та фільтрація сенсорів у DOM

## Дисципліна: WEB-програмування

**Виконала:** студентка групи КН-31 Білецька Христина  
**ВСП «Фаховий коледж інформаційних технологій НУ „Львівська політехніка“»**  
**Викладач:** Скалоцький Роман Андрійович

---

### 📌 Мета роботи

Навчитися динамічно відображати дані масиву сенсорів на існуючій вебсторінці проєкту «Акустична варта» за допомогою DOM-операцій у JavaScript та реалізувати їхню зручну фільтрацію за адміністративним районом і критичним статусом.

---

### 🛠 Виконані завдання

1. **HTML-розмітка:** Додано секцію «Активні сенсори» зі шматком управління фільтрами (`<select>` для вибору району та `<input type="checkbox">` для відбору критичних статусів) та порожнім контейнером `.sensor-list`.
2. **Пошук DOM-елементів:** За допомогою методики `document.querySelector()` отримано необхідні посилання на контейнер карток та елементи фільтрації.
3. **Генерація карток:** Реалізовано функцію `createSensorCard(sensor)`, яка створює структуровані теги `article`, динамічно додає класи та бейджики залежно від стану датчика (`normal`, `warning`, `critical`) і заповнює текстовий вміст через `textContent`.
4. **Рендеринг:** Написано функцію `renderSensors()`, яка очищує вміст контейнера методом `replaceChildren()` та виводить актуальний масив карток.
5. **Фільтрація:** Створено комплексню функцію `applyFilters()`, що використовує метод масивів `.filter()` для одночасного відбору даних за обраним районом та станом чекбокса.
6. **Обробка подій:** Підключено слухачі подій `addEventListener("change", ...)` до елементів керування для автоматичного оновлення інтерфейсу при зміні параметрів.

---

### 💡 Відповіді на контрольні питання

1. **Для чого використовується `document.querySelector()`?**  
   Для пошуку та повернення першого елемента DOM-дерева, який відповідає вказаному CSS-селектору.
2. **Що робить `document.createElement()`?**  
   Створює в пам'яті новий HTML-елемент із заданим тегом (не додаючи його автоматично на сторінку до моменту виклику `append` чи `appendChild`).
3. **Для чого потрібна властивість `textContent`?**  
   Для безпечного встановлення або зчитування текстового вмісту всередині DOM-елемента (на відміну від `innerHTML`, вона не інтерпретує рядок як HTML, що захищає від XSS-ін'єкцій).
4. **Навіщо перед повторним відображенням очищувати `.sensor-list`?**  
   Щоб уникнути дублювання карток при кожній зміні фільтрів або оновленні даних на сторінці.
5. **Що повертає метод `filter()`?**  
   Новий масив, що містить лише ті елементи вихідного масиву, для яких колбек-функція повернула логічне `true`.
6. **Як отримати вибране значення з `select`?**  
   Через властивість `.value` елемента `<select>`.
7. **Як перевірити, чи checkbox увімкнений?**  
   За допомогою булевої властивості `.checked` (повертає `true`, якщо прапорець позначений).
8. **Чому після зміни фільтра потрібно знову викликати `renderSensors()`?**  
   Щоб оновити інтерфейс користувача й відобразити на екрані саме той відфільтрований масив карток, який відповідає поточним умовам.
